# CEREBRON Farm 19 — Cybersecurity

Mission: defensive cybersecurity analysis, resilience, verification and audit.

Rules:
- DEFENSE > OFFENSE
- CLAIM <= EVIDENCE
- VERIFY BEFORE COMMIT
- EXPLOITABILITY MUST BE DEMONSTRATED SAFELY, NOT ASSUMED
- NO UNAUTHORIZED ACCESS
- NO CREDENTIAL THEFT OR MALWARE DELIVERY
- SIMULATION != REAL-WORLD COMPROMISE
- SAME MODEL != INDEPENDENT EVIDENCE

Core domains: security architecture, threat modeling, IAM, network defense, application security, cloud security, cryptography review, supply-chain security, incident response, detection engineering, resilience, audit, replication and defensive red team.
